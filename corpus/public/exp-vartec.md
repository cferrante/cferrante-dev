## Call-record ingestion

At Vartec Telecom, Colleen re-architected the system that parsed binary call detail records
(CDRs) from all 12 telecom switches, consolidating 12 unstable servers onto one machine. She fixed
memory leaks and replaced polling with file-system listeners and multithreading, cutting idle CPU
to 0%, ending unscheduled reboots and giving operations real-time status.

## Auto-dialer

Executives chose Colleen as the only internal engineer to learn Java quickly and unblock a
stalled collections-vendor project. She embedded in the call center to reverse-engineer the
undocumented legacy auto-dialer, then automated it so collections agents were shown the account
details for each call, taking the agents' pain points as the requirements.

## Teradata migration

Colleen was appointed the sole engineer to work with the Teradata DBA team after earlier
cross-team efforts had stalled, and migrated critical call records from legacy SQL dialects into
optimized enterprise schemas in the data warehouse.

## Barcode scanners

Colleen reverse-engineered undocumented handheld barcode scanners in embedded C and had a working
demo on the first day, restarting an asset-tracking program that the whole engineering
department's attempts had failed to get running.
